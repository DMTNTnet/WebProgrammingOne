Question 1

What is the significance of the html element in an html document?

The html element is the root element of an HTML document. It contains all other HTML elements and tells the browser that the content is an HTML document.
Question 2

What is the purpose of the head element in an html document?

The head element contains information about the webpage that is not normally displayed on the page itself. This includes metadata, the page title, character encoding, and links to CSS stylesheets.
Question 3

What is the purpose of the title element in an html document?

The title element defines the title of the webpage. It appears in the browser tab, is used when bookmarking the page, and is displayed in search engine results.
Question 4

What is the purpose of the body element in an html document?

The body element contains the content of the webpage that is displayed to the user. This includes text, images, headings, links, tables, and other visible elements.
Question 5

What is the difference between an inline element and a block element?

A block element typically starts on a new line and takes up the full available width of its container. An inline element stays within the flow of surrounding text and only takes up as much width as its content requires. Examples of block elements include div and p, while span and a are examples of inline elements.
Question 6

What is a self-closing tag?

A self closing tag refers to an element that does not require a separate closing tag. These are called void elements. Examples include br, hr, and img. These elements do not contain content between opening and closing tags.
Question 7

Explain the syntax for adding an attribute to an HTML element?

Attributes are added inside an HTML element's opening tag. They consist of an attribute name followed by an equals sign and a value enclosed in quotation marks. For example, class="highlight" assigns the class attribute a value of highlight. Attributes provide additional information or modify an element's behavior or appearance.
